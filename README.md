🚀 Durgaprasad's Portfolio
Portfolio PreviewReactTailwind

A modern, responsive portfolio website showcasing my expertise in AI Engineering, Agentic AI, and LLM Development.

✨ Features
🎨 Modern Dark Theme - Sleek slate & amber color palette
📱 Fully Responsive - Mobile-first design
⚡ Smooth Animations - Powered by Framer Motion
🧭 Single Page Navigation - Smooth scroll between sections
📊 Interactive Skills Display - Categorized with progress bars
🎯 Filterable Projects - Filter by category
📜 Timeline Experience - Visual career journey
💬 Testimonials Carousel - Auto-rotating reviews
📧 Contact Form - Ready for backend integration
🛠️ Tech Stack
Technology	Purpose
React 18	UI Framework
Tailwind CSS	Styling
Framer Motion	Animations
Lucide React	Icons
Shadcn/UI	UI Components

🚀 Quick Start
# Clone the repository
git clone https://github.com/durgaprasad2425/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

🌐 Deployment
Vercel (Recommended)
npm i -g vercel
vercel
Netlify
npm run build
# Drag & drop 'dist' folder to Netlify
